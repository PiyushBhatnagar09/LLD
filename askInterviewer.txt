🔹 What is std::shared_ptr?
std::shared_ptr is a smart pointer in C++ (from <memory>) that maintains reference counting.

Multiple shared_ptrs can share ownership of the same object.

The object is destroyed automatically when the last shared_ptr pointing to it is destroyed.

🔹 What is std::make_shared?
std::make_shared<T>() is a safer and faster way to create a shared_ptr<T>. It:

Creates the object and the control block (reference counter) in one memory allocation.

Reduces bugs and is more efficient than doing std::shared_ptr<T>(new T).

1. ✅ Singleton Pattern
Purpose: Ensure that only one instance of a class exists in the entire system.
2. 🏭 Factory Pattern (optional)
Purpose: Create objects without specifying the exact class — useful for managing object creation based on some input.
3. 👀 Observer Pattern (optional)
Purpose: Notify multiple objects when a certain event happens — a publisher/subscriber model.
4. 🧠 What is the Strategy Pattern?
The Strategy Pattern is a behavioral design pattern that allows you to define a family of algorithms, put each in a separate class, and make them interchangeable at runtime.
